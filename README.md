# Launch Lab 21 — платформа инкубатора

Команда стартапа проходит программу по модулям, заполняет шаблоны ответов, и из этих ответов автоматически собирается one-pager проекта.

## Запуск

Откройте `index.html` в браузере двойным кликом. Не нужны сервер, сборка, деплой и интернет. Все данные хранятся в `localStorage` браузера.

## Что реализовано

**Обязательный минимум**
- Профиль проекта: название, состав команды, краткое описание.
- Три модуля по порядку: «Проблема и аудитория» → «Решение и MVP» → «Рынок и первые клиенты». Видно, какой модуль пройден, какой текущий, какие впереди.
- Шаблоны ответов: у каждого модуля свои поля, у каждого поля есть подсказка (placeholder).
- Сохранение в localStorage: ответы не пропадают после перезагрузки.
- Прогресс: сколько модулей заполнено, процент и список оставшихся модулей.
- Автосборка one-pager. Незаполненный модуль показан как «Пустой раздел», вёрстка при этом не ломается.

**Дополнительно**
- Роли без авторизации, переключатель в шапке:
  - **Участник** видит только проект своей команды; чужой проект по ссылке не откроется.
  - **Куратор** видит все команды и их прогресс, читает ответы и оставляет комментарии к модулям. Команда видит комментарии у себя.
- Предупреждение при уходе со страницы с несохранёнными изменениями.
- Печать one-pager или сохранение в PDF через браузер.

Модули заданы массивом `MODULES` в `index.html`. Чтобы добавить новый модуль, достаточно дописать объект в массив.

## Сценарий демо (3 минуты)

1. **Роль «Участник»** → «+ Создать проект» → заполнить профиль → «Сохранить и перейти к модулю 1».
2. Вписать фразу от жюри → «Сохранить ответ и открыть one-pager» → фраза уже в one-pager.
3. **Перезагрузить страницу** (F5) → ответ на месте.
4. Раздел «Решение и MVP» → показан как «Пустой раздел», вёрстка цела.
5. **Роль «Куратор»** → таблица всех команд с прогрессом → «Ответы и one-pager» → оставить комментарий.
6. **Роль «Участник»** → комментарий куратора виден в проекте команды.

«Сбросить демо-данные» на стартовом экране участника возвращает исходные демо-проекты.
